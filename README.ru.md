# HakiOS для Xiaomi Redmi Note 9 (Merlinx)

Этот проект переносит iOS 16.5 на Redmi Note 9 (Merlinx / MT6768).
Актуальные требования, состояние функций и подробные инструкции по установке
находятся в [английском README](README.md). Экспериментальная поддержка QEMU сохранена.

Установщик: `./setup-merlinx.sh`. Полная установка **удаляет все данные с телефона**;
перед её запуском прочитайте инструкции и сохраните нужные данные.
